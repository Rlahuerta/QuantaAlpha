# Web Dashboard Quick Start

## 1) Prerequisites

- Conda environment is ready
- Backend dependencies installed
- Node.js available

## 2) Start services

```bash
cd frontend-v2
bash start.sh
```

## 3) Open dashboard

- `http://localhost:3000`

## 4) Initial setup

1. Open **Settings**
2. Fill API endpoint/key/model
3. Set Qlib path and results directory
4. Save configuration

## 5) Run factor mining

1. Go to **Factor Mining**
2. Enter a natural-language direction
3. Start task and monitor logs/metrics

## 6) Run independent backtest

1. Open **Backtest**
2. Select factor library JSON
3. Choose source mode (`custom` or `combined`)
4. Start backtest
